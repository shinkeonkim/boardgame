# UX 라이팅 가이드

화면의 모든 문구(버튼·안내·오류·토스트·게임 방법·감정 표현)는 이 문서를 따른다. 새 문구를 쓰거나 고칠 때 맨 아래 체크리스트로 확인한다.

참고한 원칙
- 토스 「[토스의 8가지 라이팅 원칙들](https://toss.tech/article/8-writing-principles-of-toss)」 — Predictable hint, Weed cutting, Remove empty sentences, Focus on key message, Easy to speak, Suggest over force, Universal words, Find hidden emotion
- 토스 「[좋은 에러 메시지를 만드는 6가지 원칙](https://toss.tech/article/21021)」 — 상황·원인·해결, 스스로 해결할 방법, 사용자의 말, 쉬운 해결, 부정적 감정 줄이기
- [Microsoft 쓰기 스타일](https://learn.microsoft.com/windows/apps/design/style/writing-style), [Material 커뮤니케이션 원칙](https://codelabs.developers.google.com/codelabs/material-communication-guidance) — 버튼은 "동사(+목적어)", 사용자를 탓하지 않기, 따뜻하고 편안하게

## 1. 목소리 (Voice) — 바뀌지 않는 것

**"보드게임 모임에서 규칙을 잘 아는 친구"** 처럼 말한다.
- 친근하지만 가볍지 않게. 지금 무엇을 하면 되는지 먼저 말한다.
- 게임을 방해하지 않게 짧게. 설명은 "게임 방법"에 미루고 화면에는 지금 필요한 것만.
- 이기고 지는 순간의 감정을 헤아린다(진 사람에게 "다음 판에서 만회해요" 같은 여지).

## 2. 말투 (Tone) — 상황에 따라

| 상황 | 말투 | 예 |
|---|---|---|
| 화면 안내·버튼·오류 (제품이 하는 말) | **해요체** — `~해요`, `~하세요`, `~할 수 있어요`. 합니다체·반말 금지 | 방을 찾을 수 없어요. 코드를 다시 확인해 주세요 |
| 감정 표현 (플레이어가 친구에게 하는 말) | **친구 사이 말투(반말 포함)**, 짧은 구어체 | 오 나이스 👍 · 한 판 더? |
| 게임 방법 모달 | 해요체, 한 문장에 한 가지 | 같은 색 카드는 앞 카드보다 큰 숫자만 놓을 수 있어요 |
| 축하·결과 | 해요체 + 짧은 감탄 | 민지 님이 이겼어요! |

## 3. 규칙

### 3-1. 다음에 일어날 일을 말한다 (Predictable hint)
버튼은 **누르면 무슨 일이 일어나는지** "동사형"으로. "확인/네/완료" 같은 모호한 말은 피한다.

| 고치기 전 | 고친 뒤 |
|---|---|
| 바로 플레이 | 시작하기 (누르면 그 게임의 방 만들기·입장 화면) |
| 자세히 | 자세히 보기 |
| 관전으로 전환 | 관전하기 |
| 기다리지 않고 시작 | 지금 시작하기 |

### 3-2. 의미 없는 말을 뺀다 (Weed cutting · Remove empty sentences)
"그냥, 바로, 앞으로, 정말, 혹시" 등 빼도 뜻이 같은 말, 화면이 비어 보여서 넣은 문장은 지운다.

| 고치기 전 | 고친 뒤 |
|---|---|
| ① 닉네임을 정하고 ② 방을 새로 만들거나, 초대받은 방에 들어가세요 | (지움 — 아래 카드 두 개가 이미 말해 줌) |
| QR·링크로 받았다면 그냥 열면 돼요 | 링크로 받았다면 열기만 하면 돼요 |

### 3-3. 지금 중요한 것만 (Focus on key message)
게임 중 안내는 **"누구 차례 + 지금 할 일"** 한 줄. 규칙 설명은 게임 방법으로.

### 3-4. 소리 내어 읽기 쉽게 (Easy to speak · Universal words)
- 한자어·문어체를 쉬운 말로: 진행 중인 → 하고 있는, 해제 → 풀기, 입장 → 들어가기(버튼은 "들어가기"), 유휴 → 아무도 없는.
- 개발 용어 금지: 서버·소켓·토큰·요청 → "연결", "다시 접속".
- 유행어·밈은 감정 표현에서만(친구 사이 말). 화면 안내에는 쓰지 않는다.
- 명사로 끝내지 않는다: "게임 시작 불가" → "아직 시작할 수 없어요".

### 3-5. 강요하지 않고 권한다 (Suggest over force)
"~해야 해요" 대신 "~하면 ~할 수 있어요". 경고도 겁주지 않고 사실과 다음 행동만.

| 고치기 전 | 고친 뒤 |
|---|---|
| 플레이어가 2명 이상 필요합니다 | 2명이 모이면 시작할 수 있어요 |
| 게임 중에는 나갈 수 없습니다 | 게임이 끝나면 나갈 수 있어요. 창을 닫아도 다시 열면 이어서 할 수 있어요 |

### 3-6. 오류는 "상황 → 이유 → 할 일" (에러 메시지 원칙)
- 사용자를 탓하지 않는다("잘못 입력하셨습니다" ✕).
- 스스로 고칠 수 있으면 방법을 같이: "암호가 달라요. 방장에게 암호를 다시 물어봐 주세요."
- 규칙 때문에 안 되는 수는 **무엇을 하면 되는지**를 붙인다: "7보다 큰 숫자만 놓을 수 있어요 — 버림 더미에는 버릴 수 있어요."
- 빨간색·흔들기는 지금 해야 할 일과 다를 때만.

### 3-7. 감정을 헤아린다 (Find hidden emotion)
- 끊김: "연결이 끊겼어요. 다시 연결하는 중이에요…" (탓하지 않기)
- 판 끝: 이긴 사람 축하 + 모두에게 "한 판 더" 선택지.
- 방장이 방을 닫음: "방장이 방을 닫았어요" + 첫 화면에서 새 방을 만들 수 있다는 길.

## 4. 표기·용어 (어디서나 같은 말)

| 쓴다 | 쓰지 않는다 |
|---|---|
| 방, 방 코드, 방장 | 룸, 호스트 |
| 들어가기(버튼) / 들어왔어요 | 입장, 접속(사용자 문구에서) |
| 관전, 관전하기 | 옵저버, 관전자로 전환 |
| 차례 | 턴(타이머 이름 "턴 제한시간"만 예외) |
| 판 (한 판, 2판) · 게임(매치 전체) | 라운드, 매치 |
| 대기실 (게임 전·후에 모이는 곳) | 로비 |
| 2명, 3~4명 | 2인, 3~4인 |
| 넘기기 (할 수 있는 게 없을 때) | 패스 |
| 게임 멈추기 / 이어서 하기 | 게임 중지 / 재개 |
| 추천해요 | 권장 |
| 땅 (Crown March의 이어진 돌) | 영역 |
| 닉네임 | 이름, 아이디 |
| 감정 표현 | 이모트 |
| 님 (예: 민지 님) | 씨, 유저 |

- 숫자는 아라비아 숫자, 단위는 붙여 쓴다: 2명, 5장, 30초, 11×11.
- 문장 끝 마침표: 한 문장짜리 안내·버튼·칩에는 찍지 않는다. 두 문장 이상이면 문장마다 찍는다.
- 강조는 굵게(필요한 단어 하나), 느낌표는 축하할 때만.
- 이모지는 칩·제목 앞 아이콘 역할로만 하나. 문장 중간에 넣지 않는다(감정 표현은 예외).

## 5. 감정 표현 쓰는 법

- **실제 보드게임 모임에서 입으로 하는 말**인지 소리 내어 확인한다. 게임 해설처럼 들리면 고친다("좋은 수!" → "오 나이스").
- 6글자 안팎, 이모지는 끝에 하나.
- 약올리기는 놀리되 상처 주지 않게(외모·실력 비하 ✕). 🍵(티배깅) 같은 장난은 움직임으로 보여 준다.
- 게임 전용 말은 그 게임의 순간에 맞게: 버린 카드를 주워 갈 때, 기사로 뒤집을 때.

## 6. 체크리스트

- [ ] 해요체인가 (감정 표현 제외)
- [ ] 버튼이 "무엇을 하는지" 동사로 끝나는가
- [ ] 빼도 되는 단어·문장이 없는가
- [ ] 소리 내어 읽었을 때 한 번에 이해되는가 (한자어·개발 용어 없음)
- [ ] 안 되는 일만 말하지 않고 할 수 있는 일을 같이 말하는가
- [ ] 위 용어표와 같은 말을 썼는가
- [ ] 사용자의 기분(지는 중, 끊김, 기다림)을 헤아렸는가
