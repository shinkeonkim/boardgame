# UI·UX QA — 새 게임 14종 + 기존 2종 (2026-11-22)

## 방법

- 게임마다 봇과 한 판을 시작하고, 다섯 화면 크기로 캡처했다.
  - 1920×1080, 1366×768, 820×1180, 390×844, 844×390
  - 크기별 캡처를 한 장에 붙여 비교했다.
- 끌어다 놓기는 헤드리스 Chrome의 실제 포인터로 확인했다.
  - Corner Claim(넓은 화면·세로 태블릿)과 Number Runs
  - 확인한 것: 미리보기·강조 → 놓기 → 되돌리기
  - 배율이 걸린 화면에서 고스트가 포인터 아래 있는지도 봤다 (Crown March·Expedition Lines).
- 꾸미기(스킨): 고른 값이 저장되는지, 다른 게임에도 이어지는지, 모달이 맨 위에 뜨는지 확인했다.

## 찾은 문제와 처리

### 모든 게임 공통

| # | 문제 | 원인 | 처리 |
|---|---|---|---|
| 1 | 큰 모니터·세로 태블릿에서 요소가 아주 작고 빈 공간만 넓음 | 고정 픽셀 크기 + 최대 너비 1280px | 화면 맞춤 배율 `fitZoom`(최대 1.7배). Crown March·Expedition Lines에도 적용 |
| 2 | 봇이 둘 때마다 「○○ 님 차례」 스플래시가 판 가운데를 가림 | 남의 차례에도 스플래시 | 스플래시는 내 차례에만. 도전·막기 대기 창은 소리만(`quiet`) |
| 3 | 손패 패널 등에 설명 없는 큰 빈칸이 생김 (Row Six, Bluff Dice …) | 공용 `.center`에 로딩 화면용 `padding-top: 30vh` | `.page.center`에만 적용 |
| 4 | 카드가 바뀌어도 움직임이 없어 무엇이 달라졌는지 모름 | 상태가 바뀌면 바로 다시 그림 | FLIP 움직임(`data-flip`): 손패 → 줄·시장 → 예약 등 |
| 5 | 내 차례 배너 오른쪽 표시(「1/10장째」 등)가 주황 위 주황이라 안 보임 | 대비 부족 | 흰 반투명 알약 |
| 6 | 휴대폰에서 상단 버튼이 두 줄로 넘침 | 버튼 과다 | 좁은 화면은 방장 버튼·테마·꾸미기를 「⋯」 메뉴로 |
| 7 | 휴대폰 가로에서 손패가 잘림 | 높이 부족 | 0.8배까지 줄여 맞춤 |

### 게임별

| 게임 | 문제 | 처리 |
|---|---|---|
| Bluff Dice | 좌석의 컵·숫자가 너무 작음. 「1+ 2+」 표시가 무슨 뜻인지 모름. 굴림·공개에 움직임 없음 | 컵 + 가려진 주사위 줄 + 「주사위 n개」, 「n개부터」 + 안내 문구, 굴림·공개·호가 움직임 |
| Number Vault | 가려진 하얀 타일이 빈칸처럼 보임. 틀린 추측 표시가 작음 | 금고 다이얼 뒷면, 「✕10」 칩, 타일 가져오기·끼우기 움직임 |
| Sealed Letter | 무슨 일이 있었는지 아래 한 줄로만 보임. 버린 카드는 숫자만 보임 | 가운데에 「방금 낸 카드」(누가 → 누구에게 · 결과), 가장 최근에 버린 카드는 이름까지 |
| Court Intrigue | 지금 걸린 선언(누가·무슨 역할·누구에게·막기)이 배너에만 있음. 금화가 아이콘 하나 | 가운데에 선언 카드, 금화 더미 + 개수가 바뀔 때 움직임, 상대 카드 크게 |
| Hidden Thorn | 쌓인 원판이 한 장처럼 보임(세로로 겹침). 뒤집기 움직임 없음 | 옆으로 겹쳐 쌓아 장수가 보이게, 뒤집힐 때 회전 |
| Flag Line | 전선 카드가 너무 작음(깃발 9개 칸에 비해) | 칸 너비에 맞춰 크게(최대 66px), 깃발을 차지하면 펄럭임 |
| Gem Guild | 시장 카드가 작고, 더미가 점선 상자 | 너비·높이에 맞춰 크게, 더미는 카드 뒷면, 보석 개수 변화 움직임 |
| Tile Atelier | 타일이 바뀌어도 움직임 없음 | 새 타일이 톡 나타남(공장 채우기·줄·벽), 공장 타일 크게 |
| Corner Claim | 클릭 두 번만 가능, 조각이 작음, 세로 태블릿에서 조각 줄이 밀림 | **끌어다 놓기**(휠/R 회전, 오른쪽 클릭/F 뒤집기, 손가락은 조금 위를 가리킴), 조각 크게, 판 높이 제한 |
| Number Runs | 타일을 고르고 묶음을 누르는 방식만 | **끌어다 놓기**(묶음·새 묶음·손으로), 놓을 곳 강조 |
| Row Six · Flare Signals · Pass the Plate · Cipher Ops | 움직임 없음 | 카드 FLIP, 질감 |

## 이어서 처리 (같은 날)

| 남았던 것 | 처리 |
|---|---|
| 휴대폰 가로에서 화면이 작음 | 낮은 가로 화면은 정보 패널을 접고(오른쪽 아래 「👥 정보」로 펼침) 테이블을 화면 전체 너비로 |
| 「규칙 요약」 패널이 글자 벽 | `SideNote`: 넓고 높은 화면은 펼친 채, 좁거나 낮은 화면은 접힌 채 시작 |
| 위치 id 없는 타일·카드는 「나타남」만 | `flyClone`: Tile Atelier 공장(가운데) → 그 사람의 줄·바닥, Flare Signals 낸 카드 → 불꽃 더미 / 버린 카드 칸 |
| Pass the Plate 넘기기 방향 | 넘어온 접시가 넘기는 방향의 반대쪽에서 밀려 들어옴 |
| Expedition Lines 2인 넓은 화면의 빈 왼쪽 열 | 2인은 마주 앉은 한 줄(상대 → 탁자 → 나), 가운데 정렬 |

| 보석 칩 위 숫자가 안 보임 | 칩 위 숫자 제거 → `CountBadge`(흰 알약). 같은 사례를 찾는 **가독성 검사 스크립트** `scripts/qa/readability.mjs` |

| 원작 이름 | 포털 카드·상세·첫 화면·게임 방법·검색에 원작 이름 |
