# 제안서 2: 더 만들 만한 보드게임 (2026-12)

1차 제안서(`2026-11-next-games.md`)의 14종을 모두 만든 뒤, 다음 후보를 다시 골랐다.
이번에는 두 갈래로 나눴다.

- **누구나 쓸 수 있는 고전**: 요트·오목·원카드처럼 규칙도 이름도 공공의 것인 게임. 원작 이름을 그대로 쓸 수 있다.
- **원작이 있는 게임**: 지금까지처럼 메커니즘만 빌리고 이름·그림·문구는 직접 만든다 (원작 이름은 「원작」으로만 표시).

## 1. 지금 플랫폼으로 되는 것 · 아직 안 되는 것

| 이미 있음 | 아직 없음 (게임을 고르면 함께 만들어야 함) |
|---|---|
| 차례·동시 선택·끼어들기(도전·막기)·협력 점수·팀 | **그림 그리기** (손가락으로 그린 선을 실시간으로 나눠 보기) |
| 2~10명, 역할별 화면, 숨긴 손패 | **실시간 반응 겨루기** (누가 먼저 눌렀나 — 서버 시각 기준) |
| 카드·칩·타일·주사위 키트, 끌어다 놓기, 효과음 | **투표·회의** (모두 찬반을 동시에 내고 공개 — 동시 선택의 응용) |
| 봇(쉬움·보통·어려움), 무중단 배포, 모니터링 | **육각형·자유 배치 지도** (카탄·카르카손류) |
| 한국어 단어 235개(Cipher Ops) | 화투 48장 그림 (직접 그려야 함) |

## 2. 평가 기준 (1차와 같음)

| 기준 | 가중치 | 무엇을 보나 |
|---|---|---|
| 폰에 잘 맞는가 | ×3 | 각자 화면이 있어서 좋아지는가 (숨긴 정보·동시 선택·자동 점수 계산) |
| 인원 폭 | ×2 | 몇 명까지 재밌게 되는가 |
| 커스텀 여지 | ×2 | 방장이 바꿀 만한 규칙이 많은가 |
| 만들기 쉬움 | ×2 | 규칙·화면 복잡도, 새 공통 기능 필요 여부 |
| 한국 인지도 | ×1 | 이름을 들으면 바로 아는가 |
| 한 판 시간 | ×1 | 15~30분 안팎이면 좋음 |

## 4. 만드는 순서 (제안)

1. **요트 다이스** (59): 주사위 키트·효과음을 그대로 쓴다. 혼자 연습도 되고, 「51 Worldwide Games」로 인지도가 아주 높다.
   - 커스텀: 족보 켜고 끄기, 보너스 기준, 굴림 횟수, 주사위 수, 팀 합산.
2. **레지스탕스형 숨은 역할** (58): 5~10명 모임용으로 지금 목록에 없는 갈래다.
   - 투표(동시 찬반 공개)를 공통 기능으로 만들면 다른 게임도 쓸 수 있다.
   - 커스텀: 역할(예언자·암살자 등), 원정대 인원표, 투표 공개 방식.
3. **원카드** (57): 한국에서 가장 익숙한 카드 놀이다.
   - 커스텀: 공격 카드(2·A·조커), 7 무늬 바꾸기, J 건너뛰기, K 한 번 더, 원카드 외치기 시간.
4. **저스트 원형 협력 단어** (55): Cipher Ops 단어 목록·팩을 재사용하고 3~8명이 협력한다. 같은 힌트를 자동으로 지운다.
5. **트리오형 짝 찾기** (54): 규칙이 단순하고 폰으로 하기 좋다(내 손패 정렬·공개 기록). 인원 3~6명.
6. **텍사스 홀덤 (칩만)** (53): 칩 키트·CountBadge를 재사용한다. 베팅 라운드를 만들어야 한다.
   - 돈이 오가지 않는 친목용임을 분명히 한다.
7. **캐치마인드형 그림** (55, 새 기능): 그림 캔버스가 생기면 파티 게임 폭이 크게 넓어진다. 점수는 높지만 공통 기능을 새로 만들어야 해서 7번째에 뒀다.
8. 그다음 후보: 더 마인드 → 킹도미노 → 하트·더 크루(트릭 테이킹 부품 공유) → 오목 → 고스톱.
   - 카탄·카르카손·장기는 화면·봇 난도가 높아 따로 판단한다.

## 5. 새로 생기는 공통 기능 (만들면 다른 게임도 씀)

| 공통 기능 | 처음 쓰는 게임 | 다시 쓰는 게임 |
|---|---|---|
| 투표(동시 찬반 → 한꺼번에 공개) | 레지스탕스형 | 마피아형, 팀 결정이 있는 게임 |
| 트릭 테이킹(선 무늬 따르기·트릭 승자) | 하트 | 더 크루형, 스페이드 |
| 그림 캔버스(선 압축·실시간 공유·다시 보기) | 캐치마인드형 | 텔레스트레이션형 |
| 베팅 라운드(콜·레이즈·폴드·올인·사이드 팟) | 텍사스 홀덤 | 허풍 게임 확장 |

## 6. 주의

- 고전(요트·원카드·오목·장기·고스톱·하트·홀덤)은 이름을 그대로 써도 되지만, 특정 상품의 그림·상표(예: 「야추」 앱 화면, 화투 회사의 그림)는 쓰지 않는다. 화투 그림은 직접 그린다.
- 원작이 있는 게임은 지금처럼 이름·그림·문구를 직접 만들고, 원작은 `meta.ts`의 `original`로만 표시한다.
- 홀덤·고스톱은 실제 돈·현물 교환 기능을 넣지 않는다 (친목용 점수만).
