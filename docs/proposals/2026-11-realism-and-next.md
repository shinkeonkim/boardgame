# 실감 나게 · 다음에 설계할 것 (2026-11)

두 가지를 정리한다.

1. **실감**: 숫자·요약으로 보여 주던 것을 실제 탁자 위 물건처럼 보이게 하는 요소. 게임마다 지금 상태를 조사하고, 이번에 적용한 것과 다음 후보를 나눴다.
2. **다음 설계**: 게임 바깥(플랫폼)에서 더 만들 수 있는 것과 새 게임 후보.

원칙: 사실감은 **정보를 더 빨리 읽게 할 때만** 넣는다. 꾸밈 때문에 숫자를 세어야 하거나 폰에서 스크롤이 생기면 안 된다.

- 정확한 수는 늘 알약(CountBadge)이나 글자로 함께 둔다.
- 폰 화면 맞춤 검사(`scripts/qa/mobile-fit.mjs`)를 통과해야 한다.
- `prefers-reduced-motion` 이면 움직임을 끈다.

| **Gem Guild** | 산 카드를 「색별 장수」 숫자로만 | 넓은 창(1280×700 이상)에서는 산 카드를 **색별로 겹쳐 쌓아** 다 보여 줌(위 카드의 점수·보석 띠가 보이게). 「모두의 상단 펼쳐 보기」로 모든 사람의 상단을 실제 탁자처럼 한 화면에 |

| Gem Guild | 예약 카드는 개수만 | 시장에서 예약 = 앞면, 더미에서 몰래 예약 = **뒷면**(단계 + 자물쇠) |

| 공통 | 잠깐 뜨는 알림이 판을 가림 | 알림은 위쪽 차례 띠 위에만 |

### 다음 후보 (게임별)

우선순위: ★★★ = 정보가 더 잘 읽힘, ★★ = 손맛, ★ = 분위기.

| 게임 | 후보 | 우선 |
|---|---|---|
| Expedition Lines | 상대 탐험대 열을 넓은 창에서 겹친 카드 기둥으로(지금은 작게). 덱 두께 = 남은 장수 | ★★★ |
| Flag Line | 깃발 주인이 정해지면 깃발이 그쪽으로 넘어가는 애니메이션. 확정된 대형에 반짝임 | ★★ |
| Tile Atelier | 공장 접시에서 타일을 집어 올리면 같은 색이 손으로 모이고, 나머지가 가운데로 미끄러짐 | ★★★ |
| Tile Atelier | 바닥 줄 감점 타일이 깨지는 효과 | ★ |
| Hold'em | 쇼다운 때 카드 뒤집기(3D flip), 팟 칩이 이긴 사람 쪽으로 쓸려 가는 애니메이션(지금은 소리만) | ★★ |
| Bluff Dice | 컵을 들어 올려 공개하는 애니메이션, 흔드는 동안 다른 사람에게도 덜컹이는 모습(Yacht 의 흔들기 재사용) | ★★ |
| Number Vault | 맞힌 타일이 뒤집히며 넘어짐(3D flip) | ★★ |
| Sealed Letter · Court Intrigue | 카드를 내면 테이블 가운데로 미끄러져 쌓이는 버린 카드 더미 | ★★ |
| One Card | 공격 카드가 쌓일수록 버린 더미가 기울어진 채 높아짐, +장수 배지 흔들림 | ★ |
| Trio Hunt | 같은 숫자 3장이 모이면 세트가 한 묶음으로 겹쳐 내 앞에 쌓임 | ★★ |
| Corner Claim | 조각을 놓을 때 「딸깍」 맞물림 + 살짝 눌림 그림자 | ★★ |
| Crown March | 기사가 돌을 뒤집을 때 동전처럼 회전 | ★★ |
| Secret Mission | 투표 카드를 모아 섞은 뒤 한 장씩 뒤집기 | ★★★ |
| 공통 | 테이블 재질 고르기(펠트·나무·리넨)를 「꾸미기」에 | ★ |
| 공통 | 햅틱: 내 차례·공격받음·카드 놓기에 짧은 진동(지원 기기만, 끌 수 있게) | ★★ |

공통 부품으로 뽑아 둘 것: 카드 3D 뒤집기(`FlipCard`), 쌓인 더미(`Pile`: 두께·각도·최대 장수), 쓸려 가는 칩(`sweepTo`)이다. 지금은 Gem Guild·Row Six·Hold'em 이 각자 비슷한 더미를 갖고 있다.

## 2. 다음에 설계할 것 (플랫폼)

| 기능 | 내용 | 왜 | 크기 |
|---|---|---|---|
| **판 다시 보기(기보)** | 끝난 판을 처음부터 한 수씩 재생. 링크로 공유 | 「방금 그 판 어떻게 된 거야?」. 서버는 이미 기록(log)을 가짐 | 중 |
| **기기 프로필·전적** | 가입 없이 기기마다 닉네임·색·전적(승률, 자주 한 게임) | 다시 올 이유. 개인정보 없이 | 중 |
| **PWA 설치** | 홈 화면에 추가, 오프라인이면 안내 화면. 매니페스트·아이콘은 이번에 만듦 | 폰에서 앱처럼 | 소 |
| **하우스룰 공유** | 방 설정을 링크(`?preset=…`)로 공유, 인기 하우스룰 모음 | 규칙을 바꿀 수 있는 게 강점 | 소 |
| **튜토리얼 판** | 봇과 정해진 패로 한 판 해 보며 규칙 익히기 | 처음 온 사람이 바로 이해 | 중 |
| **관전 개선** | 관전자는 모두의 화면을 번갈아 보기, 지연 공개(숨긴 정보 보호) | 기다리는 사람도 재밌게 | 중 |
| **리그·토너먼트** | 친구끼리 여러 판 점수를 이어서(이미 「여러 판」 있음 → 시즌으로) | 모임용 | 대 |
| **색각 보정 모드** | 색에 무늬·글자를 함께(보석·깃발·타일 색) | 접근성 | 소 |
| **검색 노출(SEO)** | 주소마다 미리 그린 head·사이트맵·구조화 데이터 (이번에 함) → 게임별 「규칙 설명」 글 페이지 | 「요트 다이스 온라인」 검색 유입 | 소 |
