# Pass the Plate — 커스텀

## 설정
| 설정 | 내용 |
|---|---|
| menu | 김밥·튀김·회·만두·초밥·겨자·젓가락·푸딩을 하나씩 켜고 끈다. 초밥을 끄면 겨자도 자동으로 꺼진다 |
| rounds | 1~5 |
| handSize | 0(자동) ~ 12 |
| pass | left / alternate |
| allowChange | 고른 카드를 공개 전에 바꿀 수 있는지 |
| showTableaus | 다른 사람이 앞에 놓은 카드를 보여 줄지 |
| turnTimerSec | 차례 제한 시간 |

## 봇
- 각 카드가 지금 내 점수에 더하는 한계 가치로 고른다.
- 어려움은 다음 사람이 원할 카드를 막는 가로채기 값을 더하고, 김밥 1등을 빼앗을 수 있는지도 계산한다.
- 2명 대결에서 어려움이 쉬움을 이긴 비율은 72%다.
- 4명(어려움 1 + 쉬움 3) 평균 점수는 어려움 36.3, 쉬움 29.8이다.
