# Go Stop (고스톱) — 규칙

전통 화투 놀이 규칙을 따른다. 카드 그림·화면은 직접 그렸다.

- 2~3명. 2명 손패 10장·바닥 8장, 3명 손패 7장·바닥 6장.
- 차례: 손패 한 장을 내 같은 달을 먹고(바닥에 두 장이면 고름, 세 장이면 모두), 더미 한 장을 뒤집어 다시 맞춘다.
- 쪽(낸 카드를 뒤집은 카드로 바로 먹음)·따닥(두 장 있는 달을 내고 같은 달을 뒤집음)·싹쓸이: 상대마다 피 한 장(설정). 뻑: 한 장 있는 달을 내고 같은 달을 뒤집으면 세 장이 바닥에 남음.
- 점수: 광 3장 3(비광 포함 2)·4장 4·5장 15, 고도리 5, 홍단·청단·초단 3, 열끗·띠 5장부터 1점씩, 피 10장부터 1점씩(쌍피 2).
- 2명 7점·3명 3점(설정) 이상이고 지난 고보다 점수가 오르면 고/스톱. 고 1·2번은 +1·+2, 3고부터 두 배씩. 피박·광박은 진 사람마다 두 배(설정). 카드가 떨어질 때까지 아무도 스톱하지 않으면 나가리.

단순화: 흔들기·폭탄·총통·첫 뻑 보너스·국진(9월 열끗) 선택은 넣지 않았다.
