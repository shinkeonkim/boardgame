# Secret Mission — 바꿀 수 있는 규칙

| 설정 | 값 |
|---|---|
| 예언자 + 그림자 사냥꾼 | 켜기/끄기 |
| 호위무사 · 가짜 예언자 · 숨은 우두머리 | 예언자를 켜야 함 |
| 외톨이 첩자 | 켜기/끄기 |
| 투표 공개 | 누가 찬반했는지 / 수만 (익명) |
| 연속 부결 한도 | 3~7 (기본 5) |
| 게임 수 | 1~7 (게임마다 역할을 새로 정하고, 이긴 편 모두 1점) |
| 제한시간 | 0~180초 (지나면 대장은 자신+다음 사람들, 투표는 찬성, 원정은 성공) |

첩자 수보다 특수 첩자 역할이 많으면 시작할 수 없다.

## 봇
- 의심 점수를 매긴다. 실패한 원정의 대원은 실패 카드 수만큼 의심이 오르고, 요원 봇은 자신을 결백으로 보고 다른 대원에게 몫을 준다. 실패한 원정대를 고른 대장도 의심한다.
- 요원 봇은 자신이 빠진 원정대에는 반대하고, 마지막 부결 직전에는 찬성한다.
- 첩자 봇은 원정대에 첩자를 한 명만 넣고, 같은 편 중 좌석이 가장 앞인 첩자만 실패를 낸다. 마지막 부결 직전에는 반대해서 이긴다.
- 사냥꾼 봇은 첩자가 낀 원정대에 꾸준히 반대한 사람을 예언자로 본다.
- 대화가 없는 봇끼리의 게임에서는 첩자가 유리하다 (어려운 요원 승률 약 13%). 사람과 함께 대화하며 하는 게임이다.
