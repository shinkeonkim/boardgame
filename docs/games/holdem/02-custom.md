# Hold'em — 바꿀 수 있는 규칙

| 설정 | 값 |
|---|---|
| 처음 칩 | 200~5000 |
| 스몰 블라인드 | 1~200 (빅은 두 배) |
| 블라인드 올림 | 0(그대로) / N핸드마다 두 배 |
| 베팅 상한 | 노 리밋 / 팟 리밋 |
| 핸드 수 | 0(한 명 남을 때까지) / N핸드 뒤 칩 순위 |
| 제한시간 | 0~60초 |

## 봇
- 승률을 몬테카를로로 어림한다. 남은 카드로 상대 패와 남은 바닥을 무작위로 깔아 본다 (어려움 260번, 보통 110번, 쉬움 30번).
- 팟 오즈보다 승률이 높으면 콜한다. 승률 58% 이상이면 ½팟, 72% 이상이면 팟만큼 레이즈한다. 남은 칩이 빅 블라인드 10배 아래면 좋은 패로 올인한다.
- 어려움은 가끔 블러핑하고, 쉬움은 `pickByLevel`로 자주 실수한다.
