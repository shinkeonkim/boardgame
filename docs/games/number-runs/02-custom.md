# Number Runs — 커스텀

## 설정

| 설정 | 범위 | 기본값 |
|---|---|---|
| colors | 3~5 | 4 |
| maxNumber | 9~13 | 13 |
| copies | 1~3 | 2 |
| jokers | 0~4 | 2 |
| handSize | 8~16 | 14 |
| initialMeld | 0~50 (0이면 조건 없음) | 30 |
| rounds | 공통 | |
| turnTimerSec | 공통 | |

## 봇

- 손 안의 줄과 무리 후보를 모두 찾는다. 겹치지 않게, 큰 것부터 고른다.
- 등록 뒤에는 남은 타일을 테이블 묶음에 이어 붙인다.
- 어려움 단계는 조커를 아끼고, 높은 숫자부터 털어 낸다.
- 어려움 대 쉬움 30판에서 어려움이 모두 이겼다.
