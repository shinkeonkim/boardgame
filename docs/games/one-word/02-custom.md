# One Word — 바꿀 수 있는 규칙

| 설정 | 값 |
|---|---|
| 카드 수 | 5~20 |
| 단어 묶음 | 모든 단어 · 자연·동물 · 일상·음식 · 모험·상상 (Cipher Ops 단어 목록 공유) |
| 지워지는 힌트 | 비슷한 것도 (자모 비교) / 똑같은 것만 |
| 틀리면 다음 카드도 잃기 | 켜기/끄기 |
| 힌트 쓰는 시간 · 맞히는 시간 | 0~120초 (지나면 힌트 「…」, 맞히기는 넘김) |

## 봇
- 단어마다 붙은 연상 태그를 힌트로 쓴다. 보통·어려움 봇은 좌석마다 다른 태그를 골라 겹치지 않게 하고, 쉬움 봇은 아무 태그나 쓴다.
- 맞힐 때는 남은 힌트가 태그에 가장 많이 들어 있는 단어를 고른다. 아무것도 안 맞으면 넘긴다 (쉬움 봇은 아무거나 답한다).
- 13장 중 평균 정답: 어려움 약 6장, 쉬움 약 0장.
