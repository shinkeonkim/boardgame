# Tile Atelier — 커스텀

## 설정

| 설정 | 범위 / 값 | 기본값 |
|---|---|---|
| colors | 4~6 (벽 크기와 같음) | 5 |
| tilesPerColor | 12~30 | 20 |
| factories | 0 = 자동(인원 × 2 + 1) | 자동 |
| perFactory | 3~5 | 4 |
| freeWall | on / off | off |
| floor (바닥 감점) | 약하게 / 원작 / 세게 | 원작 |
| rowBonus | 0~5 | 2 |
| colBonus | 0~12 | 7 |
| colorBonus | 0~15 | 10 |
| maxRounds | 0 = 가로줄 완성까지 | 0 |
| rounds · turnTimerSec | 공통 설정 | |

## 봇

가져올 타일마다 점수를 매긴다:
- 줄을 완성하면 그 칸의 인접 점수를 더한다.
- 줄을 진행만 시키면 작게 더한다.
- 바닥으로 떨어질 타일의 감점을 뺀다.

어려움 단계는 여기에 세 가지를 더 본다:
- 위쪽 짧은 줄을 먼저 채운다.
- 세로줄·색 보너스를 노린다.
- 다음 사람이 줄을 채울 색을 가로챈다.

어려움 대 쉬움 30판에서 어려움이 모두 이겼다.
