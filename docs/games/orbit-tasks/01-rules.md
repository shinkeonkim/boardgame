# Orbit Tasks (궤도 임무) — 규칙

메커니즘: The Crew (Thomas Sing). 이름·그림·화면은 직접 만들었어요.

- 3~5명 협력. 색 4가지 1~9 + 로켓 1~4(으뜸) 40장을 모두 나눔. 로켓 4를 가진 사람이 대장.
- 임무마다 과제 카드를 공개, 대장부터 하나씩 맡음. 맡은 사람이 그 카드가 든 트릭을 가져가야 성공, 다른 사람이 가져가면 실패.
- 처음 낸 색을 따라 냄. 순서 표시 과제는 1번부터 차례로.
- 신호: 임무마다 한 번, 트릭 사이에 손패 한 장을 가장 높음·가장 낮음·하나뿐으로 공개.
- 성공하면 다음 임무에 과제 +1.
