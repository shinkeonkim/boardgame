# Corner Claim — 커스텀

## 설정

| 항목 | 값 |
|---|---|
| mode | classic / duo |
| size | classic 14~22, duo 12~16 |
| pieceSet | full 21 / medium 15 / small 9 |
| scoring | advanced / basic |
| rounds | 공통 |
| turnTimerSec | 공통 |

## 봇

놓을 자리마다 점수를 매긴다:

- 조각 크기
- 새로 생기는 내 모서리 자리 수 (보통 이상)
- 어려움에서만 추가:
  - 상대 모서리 자리를 덮는 수
  - 초반에는 가운데로 뻗는 쪽에 가산

둘이서 모드에서 어려움이 쉬움을 12판 모두 이겼다.
