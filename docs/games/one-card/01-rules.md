# One Card — 규칙 (전통 카드 놀이 원카드)

트럼프 52장과 조커 2장을 쓴다. 규칙과 이름 모두 공공의 것이고, 카드 그림은 직접 그렸다.

1. 7장씩 나눠 주고 한 장을 펼친다 (특수 카드가 아닌 것).
2. 차례마다 버린 카드와 무늬나 숫자가 같은 카드를 한 장 낸다. 조커 다음에는 아무 카드나 낼 수 있다. 낼 카드가 없으면 1장 가져오고 차례를 넘긴다.
3. 공격 카드: 2 → +2, A → +3, ♠A → +5, 흑백 조커 → +5, 컬러 조커 → +7.
   - 공격을 받으면 같거나 더 센 공격 카드로 막아 넘긴다. 무늬나 숫자가 맞아야 하고, 조커는 언제나 낼 수 있다.
   - 막지 못하면 쌓인 장수만큼 받는다.
4. 7: 무늬 바꾸기 · J: 건너뛰기 · Q: 방향 바꾸기 (둘이면 한 번 더) · K: 한 장 더.
5. 한 장 남으면 정해진 시간 안에 「원카드!」를 외친다. 남이 먼저 「잡았다!」를 누르면 벌칙으로 카드를 더 받는다.
6. 먼저 다 낸 사람이 이긴다. 나머지는 남은 장수만큼 감점된다. 손패가 파산 기준을 넘으면 파산한다.
