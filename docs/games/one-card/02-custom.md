# One Card — 바꿀 수 있는 규칙

| 설정 | 값 |
|---|---|
| 처음 카드 | 4~10장 (인원 × 장수 + 1 ≤ 덱) |
| 조커 · 공격(2·A) · 7 · J · Q · K | 하나씩 켜고 끄기 |
| 원카드 외치기 | 켜기/끄기, 시간 2~10초, 잡히면 1~5장 |
| 파산 | 0(없음) 또는 손패 N장 초과 |
| 판 끝 | 한 명이 다 내면 / 한 명만 남을 때까지 (나간 순서 점수) |
| 판 수 · 제한시간 | 1~7판 · 0~60초 |

## 프리셋
기본 원카드 · 순한 맛(공격·조커 없음) · 매운 맛(5장·벌칙 3·15장 파산) · 끝까지 순위 · 외치기 없이

## 봇
- 공격·조커는 막기용으로 아껴 두고, 다음 사람 카드가 2장 이하일 때 쓴다.
- 같은 무늬가 많은 카드부터 내고, 7을 내면 손에 가장 많은 무늬를 고른다.
- 원카드 창에서 쉬움 봇은 가끔 외치기를 깜빡한다. 남을 잡는 확률은 어려움일수록 높다.
