# Hidden Thorn — 커스텀

## 설정

| 설정 | 범위 / 값 | 기본값 |
|---|---|---|
| roses | 2~5 | 3 |
| thorns | 1~2 | 1 |
| winPoints | 1~4 | 2 |
| chooseOwnLoss | on / off | on |
| randomLoss | on / off | on |
| rounds | 공통 | |
| turnTimerSec | 공통 | |

## 봇

- **안전 수 계산**: 내 더미에 가시가 없을 때만 계산한다. 내 장미 수에 남의 맨 위가 장미일 확률을 더해, 확률 0.5를 넘는 데까지 센다.
- **가시를 깐 경우**: 이기면 안 되므로 입찰을 조금 올려 허풍을 친 뒤 포기한다.
- **어려움 난이도**: 입찰한 사람의 더미를 더 안전하다고 본다.
- **성능**: 2명 대결에서 어려움이 쉬움을 77% 이긴다.
