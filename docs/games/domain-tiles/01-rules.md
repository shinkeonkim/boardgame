# Domain Tiles (영지 도미노) — 규칙

메커니즘: Kingdomino (Bruno Cathala). 도미노 구성·이름·그림·화면은 직접 만들었어요.

- 2~4명. 도미노 48장(땅 6가지, 칸마다 왕관 0~3). 2명 24장(7×7 이면 48장), 3명 36장, 4명 48장. 2명은 한 사람이 두 번씩 고른다.
- 처음 줄을 무작위 순서로 고른 뒤, 지금 줄의 도미노를 번호 순서(위에서부터)대로 놓고, 놓은 사람이 다음 줄에서 하나를 고른다.
- 놓기: 한 칸 이상이 성이나 같은 땅에 닿아야 하고, 왕국은 5×5(또는 7×7)를 넘을 수 없다. 놓을 곳이 없으면 버린다.
- 점수: 같은 땅으로 이어진 구역마다 칸 수 × 왕관 수. 보너스(선택): 성이 가운데면 +10, 꽉 채우면 +5.
