# Yacht Dice — 바꿀 수 있는 규칙

| 설정 | 값 | 설명 |
|---|---|---|
| 족보 | 기본 요트 / 확장 | 확장: 트리플(같은 눈 3개, 5개 합) 추가, 풀하우스 25, 스트레이트 30/40. 요트 칸을 50으로 채운 뒤 또 요트가 나오면 +100 |
| 굴리기 | 1~5번 | 기본 3번 |
| 보너스 기준·점수 | 0~105 · 0~100 | 기본 63점 이상 +35 |
| 진행 | 한 명씩 / 모두 동시에 | 동시에: 각자 자기 주사위·점수표로 같은 차례를 한꺼번에 진행. 모두 적어야 다음 차례 |
| 게임 수 | 1~5 | 게임마다 새 점수표, 점수 합산 |
| 제한시간 | 0~120초 | 시간이 지나면 안 굴렸으면 굴리고, 굴렸으면 가장 점수 높은 칸 |

## 프리셋
- 기본 요트 · 모두 동시에 · 확장 족보 · 넉넉하게(4번) · 한 번 더 어렵게(2번, 기준 73)

## 인원
- 1명(혼자 연습)부터 8명. 봇: 남길 주사위 32가지를 몬테카를로로 비교하고, 칸마다 「기대 대비」 가치(보너스 진행, 요트·스트레이트를 0으로 버리는 손해)를 따진다.
