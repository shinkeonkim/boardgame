# Yacht Dice — 규칙

전통 주사위 게임 요트(Yacht)의 규칙을 그대로 따른다. 규칙과 이름 모두 공공의 것이라 원작 이름을 쓴다.

## 구성
- 주사위 5개, 점수표 12칸 (확장 족보는 13칸). 1~8명.

## 차례
1. 주사위 5개를 굴린다.
2. 남길 주사위를 고르고 나머지를 다시 굴린다. 한 차례에 3번까지 굴린다.
3. 점수표의 빈 칸 하나를 골라 지금 주사위로 점수를 적는다. 맞지 않는 칸이면 0점이다. 한 칸은 반드시 채운다.

## 점수
| 칸 | 조건 | 점수 (기본) |
|---|---|---|
| 1~6 | — | 그 눈이 나온 주사위의 합 |
| 보너스 | 1~6 합 63 이상 | +35 |
| 초이스 | 아무 조합 | 5개의 합 |
| 포카드 | 같은 눈 4개 이상 | 5개의 합 |
| 풀하우스 | 3개 + 2개 (5개 같아도 됨) | 5개의 합 |
| 스몰 스트레이트 | 4개 연속 | 15 |
| 라지 스트레이트 | 5개 연속 | 30 |
| 요트 | 5개 모두 같음 | 50 |

## 끝
- 모두의 점수표가 다 차면 합계가 가장 높은 사람이 이긴다.
