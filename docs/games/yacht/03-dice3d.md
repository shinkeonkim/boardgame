# Yacht Dice — 3D 주사위 (물리)

`web/src/dice3d.tsx`는 three.js(그리기)와 cannon-es(물리)로 만든다. 따로 나눠 나중에 불러오므로(lazy) 첫 화면 크기는 그대로다. 이 묶음은 gzip으로 약 145KB다. WebGL이 없거나 불러오는 동안에는 평면 주사위(2D)를 보여 준다.

## 결과는 서버가 정한다
1. 던질 때 물리 시뮬레이션을 화면 밖에서 끝까지 돌린다 (1/60초 간격, 최대 4초, 모두 멈추면 끝). 그동안 프레임을 기록한다.
2. 멈춘 자세에서 위를 향한 면을 찾는다. 그 면에 서버가 준 눈이 오도록 주사위의 면 그림을 바꿔 붙인다.
   - 정육면체 회전 24가지 중 하나로 표준 눈 배치를 돌린다. 그래서 마주 보는 면의 합 7이 유지된다.
3. 기록한 프레임을 재생한다. 굴러서 멈춘 면이 곧 서버 결과다.
4. 멈춘 뒤에는 가장 가까운 반듯한 자세로 0.35초 동안 한 줄로 모인다.

## 남기기
- 주사위를 누르면 Raycaster로 맞은 주사위를 찾는다. 남긴 주사위는 뒤쪽 줄로 살짝 들리고 금색 받침이 생긴다.
- 다음에 던질 때 남긴 주사위는 고정 물체(STATIC)가 되어, 굴러오는 주사위가 부딪힌다.
- 키보드와 화면 읽기 프로그램용으로 보이지 않는 남기기 버튼(`.sr-only`)을 둔다.

## 화면
- 바닥은 그림자만 받는 투명 면이라 CSS 펠트 색이 그대로 보인다.
- 위에서 거의 내려다보는 시점이라 윗면이 잘 읽힌다. 화면이 좁으면 카메라가 멀어져 판 너비가 다 보인다.
- 움직임 줄이기 설정을 켜면 굴리지 않고 바로 결과를 놓는다.
