# Sketch Quiz — 규칙 (메커니즘 출처: Pictionary, Robert Angel)

이름, 그림판, 문구는 직접 만들었다. 단어는 Cipher Ops 단어 목록(`@bg/cipher-ops-engine`)을 함께 쓴다.

- 차례대로 한 명이 그리는 사람이 된다. 한 사람이 `rounds`번씩 그린다.
- 그리는 사람은 보기 `choices`개 중 하나를 15초 안에 고른다. 안 고르면 첫 번째 단어로 정한다. 「넘기기」를 누르면 점수 없이 다음 사람으로 간다.
- `drawSec`초 동안 그린다. 선은 0~1000 좌표를 32진수 두 글자로 줄여 보낸다. 0.15초마다 이어진 조각을 보낸다.
- 맞히는 사람은 채팅으로 답한다. 띄어쓰기와 대소문자는 무시한다. 먼저 맞힐수록 10·8·6·5·4점, 그 뒤로는 3점이다.
- 오답은 모두에게 보인다. 정답을 품거나 편집 거리 1인 말은 가려서 보여 준다. 한 글자 차이면 보낸 사람에게만 「아깝다!」를 띄운다.
- 그린 사람은 맞힌 사람마다 +3점이고, 모두 맞히면 +2점을 더 받는다.
- 힌트: 시간이 35% 지나면 초성을, 65% 지나면 (두 글자 이상이면) 한 글자를 보여 준다.
- 모두 맞히거나 시간이 다 되면 정답을 6초 동안 보여 주고 다음 사람으로 넘어간다.
- 서버 타이머는 단계마다 새로 잰다 (`phaseKey`). 맞히는 사람에게 「대신 진행」을 하면 그 그림만 포기한다.
