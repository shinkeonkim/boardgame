# Sketch Quiz — 바꿀 수 있는 규칙

| 설정 | 값 |
|---|---|
| 한 사람이 그리는 횟수 | 1~3 |
| 그리는 시간 | 30~150초 |
| 고를 단어 | 1(정해진 단어)~4개 |
| 초성·글자 힌트 | 켜기/끄기 |
| 단어 묶음 | 모든 단어 / 자연·동물 / 일상·음식 / 모험·상상 / 직접 넣기 (5~300개) |

직접 넣은 단어는 다른 사람 화면에 개수만 보낸다.

## 봇
봇은 넣을 수 없다 (`bots: false`). 그림을 그릴 수 없고, 그림을 못 보는 봇의 짐작은 게임을 망친다. 서버가 봇 넣기를 거절하고, 대기실에는 「봇 넣기」가 없다.
