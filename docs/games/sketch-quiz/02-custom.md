# Sketch Quiz — 바꿀 수 있는 규칙

| 설정 | 값 |
|---|---|
| 한 사람이 그리는 횟수 | 1~3 |
| 그리는 시간 | 30~150초 |
| 고를 단어 | 1(정해진 단어)~4개 |
| 초성·글자 힌트 | 켜기/끄기 |
| 단어 묶음 | 모든 단어 / 자연·동물 / 일상·음식 / 모험·상상 / 직접 넣기 (5~300개) |

직접 넣은 단어는 다른 사람 화면에 개수만 보낸다.

## 봇
- 그림을 못 그린다. 그릴 차례가 오면 넘긴다.
- 맞힐 때는 단어 묶음에서 글자 수, 띄어쓰기, 보이는 초성·글자가 맞는 후보를 골라 던진다. 이미 나온 오답은 뺀다.
- 쉬움 봇은 35%, 보통 봇은 15% 확률로 엉뚱한 단어를 던진다. 직접 넣은 단어 묶음에서는 후보를 모른다.
